# gRMathRand2 @ 0x44c900

Exact at 100.00%, 8/8 instructions, with all three masked operands clean.

Windows advances its 0x1fff-entry `int` table cursor modulo 0x1fff and returns
the next cached 15-bit value. Android and iOS preserve the authored
`gRMathRand2()` name over a compact 16-bit table; that storage-width difference
does not change the gameplay value contract.
